About Me
I am a third-year Computer Science undergraduate interested in mathematics, artificial intelligence, and computer vision.
My interest in this field comes from exploring how mathematical concepts and computational algorithms can be translated into practical solutions for image analysis and visual understanding.
This repository presents a collection of image-processing methods that I have independently implemented using Python. My goal is to understand the underlying mathematical principles of these algorithms rather than simply rely on ready-made library functions.

Projects
1. Basic Image Operations

Implementations of fundamental image manipulation techniques:

Grayscale image inversion.

Grayscale image binarization.

RGB image thresholding.

Pixel-level manipulation and diagonal modification.

2. Image Filtering

Implementations of neighborhood-based filtering techniques using NumPy:

Maximum Filter: Replaces each pixel with the maximum value in its 3×3 neighborhood.

Minimum Filter: Replaces each pixel with the minimum value in its 3×3 neighborhood.

Average Filter: Replaces each pixel with the average intensity of its 3×3 neighborhood.

3. Edge Detection

Sobel Edge Detection

Implemented the Sobel operator using two 3×3 convolution kernels to calculate horizontal and vertical image gradients.
The gradient magnitude is calculated using:

G=Gx2+Gy2

The implementation performs convolution manually using Python and NumPy.

4. Image Inpainting

Exploration and implementation of image inpainting techniques to reconstruct missing or damaged regions in images.

More details and visual results are included in the corresponding project folder.

This repository includes original images and processed outputs to demonstrate the behavior of the implemented algorithms.

I aim to document the results of each method and understand its mathematical foundations, advantages, and limitations.

I am particularly interested in understanding how mathematical structures and computational methods can help machines interpret visual information.

Through these projects, I hope to strengthen my theoretical understanding, improve my implementation skills, and develop the foundations needed to contribute to research in computer vision and artificial intelligence.
